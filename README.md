# rConfig Connection Templates — Converted Data

This repository contains the rConfig community connection templates converted from YAML to JSON for use with MikroWizard's connection template system.

## Source

The original templates are from [rConfig/rConfig-templates](https://github.com/rconfig/rConfig-templates) (GPL-3.0).

## Contents

| File | Description |
|------|-------------|
| `LICENSE` | GPL-3.0 license (from original rConfig repository) |
| `templates.json` | 59 device connection templates in JSON format |
| `brands.json` | 25 vendor brand definitions |
